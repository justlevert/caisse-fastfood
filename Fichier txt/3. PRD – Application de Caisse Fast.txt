📄 PRD – Application de Caisse Fast-Food (Tacos/Burgers)
🟢 1. OBJECTIF DU PROJET

Développer une application de caisse professionnelle pour un fast-food (tacos, burgers), utilisée principalement sur tablette (iPad / Android), avec :

Interface rapide et tactile
Gestion des commandes en temps réel
Historique et dashboard avancé
Paramétrage complet (produits, tickets, imprimantes)
Utilisation personnelle (non SaaS commercial au départ)
🟢 2. STACK TECHNIQUE (OBLIGATOIRE)
Frontend : Next.js + TypeScript
UI : Tailwind CSS
Backend / DB : Supabase
Responsive : optimisé tablette (iPad + Android)
Mobile secondaire : interface simplifiée pour scan facture
